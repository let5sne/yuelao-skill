月老.

她比任何算法都更懂你。 因为你们的对话，从不离开你的电脑。

一位 AI 婚恋顾问，住在你自己的设备里。她跟你聊天、替你筛选、居间传话—— 像一个真正在帮你操心的人，而不是一个推荐列表。

相亲 App 让你左滑右滑，看照片，填条件——像在电商平台挑商品。

月老跟你聊天。

她怎么工作

  1. 她跟你聊天，不让你填表

    城市、工作、下班后干什么。像朋友一样聊五分钟，你不会意识到自己在"建档"。 她也会问一些更难的——"一个人有趣但不稳定，另一个无聊但靠谱，你选哪个"。

  2. 候选都经她过一遍，最多 3 个走到你面前

    后台按硬条件和向量匹配筛出候选，一轮最多入库 5 条推荐；她再按对你的了解筛一遍， 最多让你看到 3 个。她知道档案里写不出来的事—— 你嘴上说"学历无所谓"，但每次聊到高学历的人语气都不一样；你三次回避异地话题， 却没把它写进"不能接受"。

  3. 想问什么，她替你去问

    还没交换联系方式之前，两边的月老在中间传话。你说"帮我问问她周末干嘛"， 她会包装成合适的措辞发过去。话说得太冲，她帮你换个说法； 第一轮就问收入，她会建议你缓缓。

你的话只在你这里

  • 聊天原文 你的电脑 不发到匹配服务器。注意这不算"不出网"：月老跑在你自己的 agent 里，对话仍会经过你选的那个模型服务。
  • 结构化画像 服务器 → 两类外部服务 年龄、城市、性格标签这类，不含姓名——匹配引擎要用它。它还会发给算向量用的 embedding 服务；判断打分层开启时，也会把同样的结构化字段发给 TypeSafe。
  • 联系方式 你的电脑 → 双方同意后交换 平时只在本地。必须你和对方互相点了同意，并且你明确让她提交，才会经服务器交换给对方。

说实话的部分：传话内容和她的筛选理由存在服务器上（要中转、要优化匹配）。 端到端加密的中转在路线图里——那之后服务器会从"承诺不看"变成"看不了"。 随时可以让她把你的数据全部删掉。

装上她

一行命令。之后她就在你的 agent 里了。

git clone https://github.com/let5sne/yuelao-skill.git ~/.claude/skills/yuelao

需要 curl 和 jq。支持 Claude Code 及其他兼容 Agent Skills 的工具。

然后对你的 agent 说一声 月老，或者"我想找对象"。

内测中——池子还很小，匹配到测试账号时她会明确告诉你。
